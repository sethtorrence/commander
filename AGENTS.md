# Commander

A personal command center that runs entirely on the User's own machine. Planning is in progress on the wayfinder map in this repo's GitHub Issues (label `wayfinder:map`).

## Agent skills

### Issue tracker

GitHub Issues on sethtorrence/commander, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels, each named after its role (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
